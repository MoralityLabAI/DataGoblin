# Rank-aware noisy verifier curriculum

Source: https://github.com/MoralityLabAI/LoopedTransformers/tree/b7c4754265495cd5d952d012ad9e46ef17bff076/experiments/logrank_bpd_10.

The 10 pilot uses no singleton labels. A known coordinate map, uniform hidden signs, and controlled-rank even parity equations define the task. Exact basis decoding solves all identifiable clean queries; a four-restart straight-through hard-sign proxy scores near chance. At 15% independent teacher noise, the exact redundant-equation posterior answers 740/768 identifiable queries correctly; with a 90% confidence cutoff it answers 683/768, all correct in this sample. At 35% noise the same cutoff abstains everywhere. Four extra in-span verifier calls provide little realized improvement; target-aware expected Brier selection is an adaptive control and does not consistently outperform random.

Curriculum contract: keep public incidence masks, offline hidden signs, observation likelihood model, rank, row-span membership, nullspace certificates, query costs and actual verifier outcomes. Route to exact GF(2) decoding when observations are clean and to uncertainty-aware noisy decoding otherwise. Never label an out-of-span failure as a reasoning failure under a uniform hidden-sign prior. Separate probes that increase rank from probes that reduce uncertainty within an existing span. For scalable decoding compare sparse parity-check message passing, information-set decoding and exact enumeration at small rank. Use channel capacity as a necessary budget constraint, not a performance guarantee. In future learned acquisition evaluation freeze fresh generator roots, compare random/entropy/target-risk controls at equal calls, and record coverage and calibration.
