# ALG-DESCENT-13 prospective admissible cost-partition bounds (2026-11-27)

Synthetic weighted acyclic Horn proof planning only, V11 graph generator and V12 anytime architecture. No learned weights or training. Fresh IID 12 roots 810000..810011 (n=10/11/12/13 cyclic); fresh OOD 24 roots 820000..820023 (n=16/17/18 cyclic, shared/uniform/clustered rotated by block as V12). Public development cohort, not sealed. All arms share exact rule binding, legal successor enumeration, positive costs, best-g dominance/reopen, immutable proof paths, verified direct FF incumbent/completions, and retain all unresolved OPEN. Order by g+admissible bound, ties smaller bound then g then insertion serial. Snapshots 0/4/16/32/64/128 expansions. Reference optimum/values computed offline after search. No memory eviction.

Four bounds: (A) optimized hmax. (B) max(hmax, mandatory-fact cost): compute obligatory unknown facts for goal via topological union of each rule's premise obligations, intersection across alternate rules, and include head; sum min head-deriving rule costs once per mandatory unknown fact. (C) goal-threshold cost partition: initialize residual rule costs equal original; compute residual hmax distances, threshold H=distance(goal). If H>0, Z contains relevant goal-ancestor unknown facts with distance >=H. Cut comprises every rule with head in Z and no premise in Z. Each such rule has positive residual cost; every legal proof must first enter Z and hence use a cut rule. Charge delta=min residual cost of cut; subtract delta from each cut rule, accumulate delta, repeat until residual hmax(goal)=0. Bound max over prefixes of accumulated charge + residual hmax. (D) same cuts, but use max(residual hmax, residual mandatory cost) at every prefix. Record cut rounds, scanned rules and bound computation time; no model. At least one positive residual cost becomes zero each round, so <= number of rules. Admissibility follows by assigning charges to necessary cuts and bounding residual proof cost. Consistency not assumed.

Primary gate for D vs A: all proofs and certified intervals valid; at least 25% lower mean expansions to certification at cap128 OR >=20% lower mean normalized interval width at budget16, with >=16/24 strict root wins on same metric; equal closure and no fewer optimal certifications at 128. If all runs certify, report exact expansion counts. Report B/C separately, paired root bootstrap descriptive, runtime and preprocessing tradeoff, no wall-time claim absent measured advantage. All timings single randomized arm-order runs, instrumented, report heuristic calls and bound work. Logical state counts only, no physical memory claim.
