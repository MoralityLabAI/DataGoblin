# Non-claims

DataGoblin v0.1 does not establish:

- constitutional alignment;
- autonomous scientific competence;
- safe arbitrary code generation or execution;
- transfer to real game agents or deployed systems;
- superiority of HRM, TRM, or LDT;
- effectiveness of an approximately 1B specialist;
- capability gains beyond the toy `causal_switches_v1` environment.

The included experiment is deterministic toy smoke evidence for orchestration integrity. Its learner, environment, and distributions are deliberately small and transparent. A favorable toy result is not external evidence, and a null or negative result would remain equally valid as a pipeline record.
