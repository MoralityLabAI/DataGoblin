# DISTILL-21: critical optimum witnesses and selective exclusion compilation

Registered as an independent follow-up while DISTILL-20's full timing study is running. No selection of thresholds from the preceding evaluation. This experiment reuses its paired replay harness, with explicit arm factories; its previous default parameters and behavior are unchanged.

## Exact principle

Fix the current numerical objective and exclusions from all sources except s0. Let A* be the exact packed-optimum subset on this fixed scope. Removing any candidate outside A* preserves that subset's feasibility, and restricts the set of competitors. Thus it preserves the unique packed optimum (including deterministic lexicographic ties). Only members of A* are critical omissions. Fixed/already unaffordable omissions are canonicalized to no additional exclusion.

A 32-entry lazy LRU memo holds numerical selections for requested omissions. The first query is solved directly; exact repeated keys do not initiate extra compilation. On a second novel request the witness arms solve the unrestricted fixed-scope optimum once, then answer inert omissions from it. Only novel critical misses require direct work. The selective atlas arm compiles all critical omission scores after four such misses. Store forward prefix snapshots only before critical IDs, sweep one suffix backwards, and combine prefix/suffix packed values across each capacity split. Construction takes O(nC + kC) time and (k+2)(C+1) temporary DP cells, where k=|A*|; the original atlas uses (n+2)(C+1) cells. Retain at most k packed scores and the bounded memo. If the temporary cell bound 150,000 would be exceeded, fall back to exact direct solves until a new fixed scope. All scopes are reset on a fixed-exclusion change; new public objectives reset the planner. Numerical memory never contains receipt/frame authority. This is a logical cell bound, not measured RSS.

## Frozen comparison

Six arms: native reference, packed dense, DISTILL-20 delayed atlas, lazy exact omission memo, delayed full-optimum witness plus memo, and witness plus selective critical atlas. Native cold episodes: eight fresh TRAIN and eight calibration roots per width 5/12/16, both native variants, 576 host-verified executions. Public solver replay uses eight new underlying roots per width/regime cell (generator indices 1000..1007, disjoint from DISTILL-20), widths 16/32/64/128, capacities 2n/8n, stable streams of 1/4/16/32 requests and a 16-request churn stream. These are paired horizons on the same roots. 4,416 requests per arm, 26,496 total. No future stream lengths supplied to any planner. Same rotated arm order and complete reference action/receipt comparison as DISTILL-20. Native host independently verifies all native episodes; wide public replay checks reference DP parity and feasible current receipt binding, not native host evaluation.

Primary comparison is total policy process CPU versus packed dense including preparation, witness solving, memo operations, atlas construction/invalidation and fallback.
