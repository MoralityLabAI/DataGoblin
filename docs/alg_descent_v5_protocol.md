# ALG-DESCENT-05 native packed cache protocol

2026-11-26. Fresh development experiment, synthetic public-witness polynomial routing only. Native implementation will use C++17 because rustc/cargo are unavailable in the local runner. No cryptographic problem solving.

Freeze v4 symbolic risk rule and train-only empirical prior using v4 training roots. Precompute the eligible candidate order by public scores, without using evaluation validity labels. Export all canonical interval polynomials and eligible candidate child polynomials, including invalid certificates, to a compact binary bank. Native exact schoolbook product verifier must check each attempted candidate and verify accepted child polynomials match their indexed subproblems. Work cap 3*n^2, call cap 8*n, hit cost 1. Root banks shared across arms. No cached validity oracle. Fresh roots: 24 IID seeds 150000..150023, degrees 8/12/16/20; 32 OOD seeds 160000..160031, degrees 24/32/40/48.

Implement exact 4-bit coefficient keys (p<=11, maximum degree 48), fixed-size preallocated cache entries holding key, recency and observed saved work. Scope cache to root and field. No probabilistic key equivalence. Capacity caps 0/64/128/256/512/1024 bytes for entry allocation (report sizeof entry, allocated slots and separate cache control and fixed pending frontier memory). Same capacity for LRU and pending-only utility. Utility is accepted pending multiplicity times max(0, paid subtree work-1), victim min value with LRU tie break; admit if new value >= victim value. Pending stack contains only accepted, not-yet-visited nonterminal children; both arms track same stack. No dynamic cache or pending allocation during a rollout. Cache flags are trusted in-process closure receipts, not portable proofs. Candidate bank, recursion stack and process/runtime allocations separately scoped; no overall physical RAM cap claim.

Independent Python reference with exact coefficient verification and same fixed-slot policy: compare closed/work/calls/rejections/hits/max occupancy per root/arm. Check exact keys across small fields and coefficient mutation; include malformed certificate tests and zero/one-slot cache controls. Native benchmark release build, repeat 25+ times per root/arm in randomized arm order, report root-average of per-root median times and work. Include cache allocation in native timing, report bank generation/export, native load and warmed rollout separately. End-to-end cold bank generation is shared Python preprocessing, not a native generator speed claim. Report native process max RSS and fixed cache/pending byte payload; no PSS claim.

Gate for pending utility: matched closure, lower mean OOD work than LRU at >=2 nonzero capacities and no higher median warmed latency at those same capacities; describe uncertainty and treat timing as host-specific. Also report native no-cache and LRU gains. Check outputs against independent reference and run ASan/UBSan if available. No neural training or native BPD/MMS integration in this iteration; packed cache is an engineering baseline for that work.
