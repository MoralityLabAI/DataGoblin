# DISTILL-22: constraint-lattice reuse

DISTILL-21 validated fixed-scope optimum witnesses but still resets numeric memory when a fixed exclusion changes. Here the numerical key is the union of currently excluded affordable candidate IDs, independent of which sources exclude them. Receipt IDs, versions and frame authority are never cached. One immutable prepared public objective defines the entire lifetime of the cache.

## Exact reuse rule

Let F be the new forbidden set and K a subset of F. Every feasible subset under F is feasible under K. If the deterministic optimum A_K under K is disjoint from F, it is feasible and remains the exact optimum under F, including packed lexicographic tie breaking. Equal union keys also permit exact reuse even if receipt IDs or source multiplicity differ. This rule never infers that an old optimum stays optimal after restoring an item. A relaxed witness must be solved exactly in the current immutable objective; conflicting witnesses cause fallback.

Three new arms: lattice_memo performs exact-key and subset-witness lookup only, with no extra solves. Lattice_relax can additionally solve one proper intersection between the current exclusion set and a recent actual query; prefer maximum cardinality then maximum prior support, with deterministic ties. Lattice_guarded requires support from at least two distinct prior actual queries. If the selected relaxation is already cached but unusable, or the newly solved relaxed optimum conflicts with the current exclusions, solve the current problem directly. No future observations are used. Bounded 32-entry LRU, eight distinct recent query keys; no prefill, no cross-objective reuse. Bitset submask enumeration limited to five excluded affordable candidates, otherwise bounded cache scan. Inert unaffordable IDs are removed from numerical keys. Only selected IDs and membership are cached. New start observation resets all memory. Scope changes do not authorize reuse of evidence: every submit binds fresh receipt IDs and frame. Host unchanged.
