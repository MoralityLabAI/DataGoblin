# ALG-DESCENT-07 / BPD-RISK-01 prospective development protocol

Scope: synthetic public-witness polynomial certificate routing; no DLP/factor discovery. Test a BPD-inspired shared rank-one recurrent risk predictor, not the full native BPD engine. Start from v2 Root's polynomial generator, retain arities/partitions and a guaranteed uncorrupted balanced binary proposal. Perturb eligible nonfallback proposals with a coefficient edit that preserves evaluations at 0 and 1. Train families: adjacent pair and nonadjacent pair in a single child. OOD families: second difference in a single child, and paired edits across two children. If an edit is impossible, leave candidate unchanged; label only by exact product. IID and OOD roots disjoint; no family ID or latent corruption rate given to predictor. Train 48 roots per train family (seeds 210000..210047 and 211000..211047), degrees 8..20. Calibration 12 per train family (220000..220011,221000..221011), degrees 12/16/20. IID 12 per train family (230000..230011,231000..231011), OOD 16 per unseen family (240000..240015,241000..241015), degrees 24/32/40/48. Public candidate/state features only (shape, coefficient statistics, field, necessary-condition fingerprints at 2 and 3, history of already rejected proposals). Do not expose generator witness factors or actual candidate validity. Offline exact labels for fitting/evaluation only. Necessary checks at 2,3 used equally by all policies as hard masks; report coverage and surviving negative count per family.

Fit train-only Laplace bucket prior using field/arity/balanced shape, plus stronger logistic residual with same public inputs. Recurrent rank-one factor model W=sum u_j v_j^T, shared over three recurrent updates, trained end-to-end BCE, three seeds 19/41/67; match feature access. MLP comparable parameter size; no full BPD decomposition of a frozen transformer. Use training data from root/subinterval candidates, with deterministic simulated history of up to two already rejected eligible distinct proposals; evaluation predictions on fixed identical history cases. Primary OOD prediction gate: at least 5% relative improvement in root-averaged log loss vs strongest of bucket/logistic/MLP controls, and improvement on both held-out families. Report Brier, negative counts and root-level paired bootstrap. Routing: exact verifier on every attempt, shared structural bound and score structural+C*(1/p-1), mask common fingerprint failures, cap 3*n^2 and 8*n, no cache to isolate prediction. Require matched closure and >=5% reduction in OOD mean work vs strongest symbolic/MLP comparator and >=20/32 root wins for a learned routing claim. Score/inference timing and preprocessing off work meter.

Component analysis: per checkpoint select a shared rank-one factor maximizing calibration log-loss increase when deleted (all roots averaged); freeze selection before evaluation. Compare ablation, opposite steering (+factor), same-norm negative random rank-one edits (8 deterministic shams), and unmodified model; intervention affects all three passes, no verifier change. Causal utility gate: targeted deletion increases OOD root-averaged log loss on both families and exceeds median sham damage by >=0.01 nats pooled; additionally report routing work with targeted ablation and shams. Sham matches parameter Frobenius norm/rank, not activation perturbation. Multiple model seeds share evaluation roots; no significance claim. Report failure if negative counts too low or component gate fails. New corruption families are public development splits, not sealed test. Preserve existing ARG-03-N seals. No native MMS/BPD claim, no Lean verification.
