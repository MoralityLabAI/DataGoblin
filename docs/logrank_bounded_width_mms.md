# Bounded-width elimination for MMS verifier repair

Source: https://github.com/MoralityLabAI/LoopedTransformers/tree/029350cdbaeda9ad8abb011ee66d2eddd2c95662/experiments/logrank_bpd_16.

16 compares weighted independent bounds, exact rank-capped connected-component integration and mini-bucket elimination on 36 fresh parity graph worlds. Identical observations, two unary readings per variable and 3n triple observations, 12/24/48 variables, known BSC .15/.35. Exact width-five inference on all 384 block/chain target cases across noise levels; at .15 170/192 certified at .9 confidence, all correct in sample. At .35 only 3/192. Dense 48D global triples have essentially vacuous intervals even with width seven. No causal or deployment claim.

Use residual graph connectivity and estimated induced scope as features for choosing solver and memory budget. For a connected low-width component, eliminate rather than enumerate the whole state space; for small quotient rank, enumerate directly; otherwise retain admissible independent-factor or mini-bucket bounds and abstain when intervals remain wide. Measure total live table bytes including integer bit length and actual process RSS, not just width or table entries. Use a costed gate on certified interval reduction per wall-time/memory/verifier unit. 16 is a kernel comparison on synthetic graphs, not a replacement for the 15 search loop. Timings concurrent; clean forkserver rerun corrected inherited RSS measurement bias and reproduced every non-timing result.

Next: connect bounded elimination to the disjoint prefix frontier of 15, test cutset selection by residual treewidth, cache reusable separator messages for multiple queries, benchmark time-matched dense controls and independent fresh generator families. For posterior confidence use exact event weight intervals conditional on the noise model; no guarantee of correctness of any individual realized answer.
