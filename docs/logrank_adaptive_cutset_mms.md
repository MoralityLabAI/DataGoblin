# Budget-gated adaptive cutset frontier

Source: https://github.com/MoralityLabAI/LoopedTransformers/tree/01e40b7c0274b40bc4b9acdfa05545a35d9b24e5/experiments/logrank_bpd_18.

18 implements an adaptive exact-integer interval controller. Each query has a disjoint cutset frontier common to both event sides. Action candidates refine a leaf with mini-bucket scope 3/5/7 or cut one/two new degree-selected coordinates. Preflight predicts join entries, live lower/upper table slots and kernel call counts. Reject an entire action if it would exceed 900n counted join entries, 45n live numeric table slots or 128 calls. Intersect old parent intervals with summed child bounds, so all accepted actions provably narrow or preserve valid posterior intervals. Adaptive prioritizes predicted exact residual plans then structural improvement per work. No claim that it optimizes information gain.

270 solver runs, 27 independent development worlds. Adaptive gives 140 exact query/noise cases versus 134 for scope5 and degree2, 67/108 certified at .15 noise (all correct in sample); degree2 certifies 66 and scope5 63. At .35 all abstain. All 48D dense candidate plans exceed the counted slot cap, so these worlds receive no table refinement. Adaptive mean elapsed time 89.2ms vs 30.0ms fixed scope5 and 73.7ms degree2, with 43.4ms in plan construction. Numeric table payload estimate peaks at 307536 bytes; process RSS about 80–81MiB, no hard RAM cap. Independent weight/ledger audit passes. Not native MMS or BPD training.

MMS recommendation: make a cached public graph/scope plan a reusable object, including per-action cost preflight and a typed ledger. Preserve disjoint-cell certificates and abstention. Start with fixed low-width elimination when an exact plan fits; apply adaptive cutsets selectively. The next headroom is repeated query-conditioned inference: reuse separator messages and extract pair marginals, and stream initial factors for dense cases. Benchmark time-matched controls and actual workspace bytes, including arbitrary precision integers. No confirmation release or native integration.
