# ZKL-18: typed term curriculum and public-reachability control

Original reference and fixtures: https://github.com/patrickdugan/zk-rusto-no-bitcoino/tree/a5c6acb571138342fb0090ef1303b46645b2ae87/integrations/zkl-nova-calibration

The typed grammar is annotated de Bruijn Sort, Var, Pi, Lam, App. Certificate targets are WF(context) and Ty(context, subject, type), with eight local inference rules. The native public compiler checks syntax, context extensions, weakening, universe imax, dependent codomain substitution and bounded beta conversion. Nova authenticates the resulting public local inference table and verifies earlier derivation references. The ZKL-17 explicit conversion circuit is separate and is not integrated into the typed fragment. Native semantics are in the verifier TCB; proof syntax and candidate inferences are public.

Native evidence: five closed typed examples, 92 rows and all eight rules; 128 additional generated K-style proposition inhabitants replayed; 4,952 total rows, maximum 67 rows and 76 public rule descriptors. Only 94/128 fit both 64-slot circuit caps. Five mutated inference descriptors rejected. The finite reference optimum is exact only when every goal-reachable judgment has one producer and its dependencies are acyclic; current native audit confirms this on the generated tables. The public Horn table also permits ordinary least-fixed-point reachability without any witness. Therefore this surface is a conformance curriculum, not a private proof market or evidence of a computational verification advantage.

Proposed next learner surface: generate missing type and context fields from annotated terms, predict the rule and proof obligations, and construct substitutions with correct scope. Hold out source syntax families and all descendants together. Require actual Lean kernel replay and a separately owned source checker; label the bounded fragment and independent cost profile. Use deterministic syntax-directed inference and memoization as controls. Retain zero coverage for invalid, omitted or capped outputs. Do not present the public candidate table as a challenging proof-search benchmark. The exact native generators are retained upstream; no training or corpus release occurred.

ZKL-17 measured 16,305 raw R1CS constraints per explicit conversion row, 34 honest rows over five fixtures, 11 forged witnesses rejected, 11,128-byte compressed proofs and all five typed endpoint examples accepted by Lean 4.19.0 without axioms.
