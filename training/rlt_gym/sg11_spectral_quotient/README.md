# SG-11: direct quotient and sparse search

Optional sparse session validates d<=32,T<=16. Given retained set S and legal action A of size k, choose R=A\S. Every member of one quotient class has the same newly paid price and the same remaining optimization problem. Fill the remaining k-|R| slots with the highest-utility members of S, ties by lowest index. Enumerate only feasible subsets of the complement. The final visit has an additive adjusted utility and can be solved by top-k directly. Fixed dual bank uses exact Python integers and prefix contribution tables, without split-mask exponential arrays. No dense action or mask allocation. Dynamic state dictionaries are still finite-work but not bounded by measured RSS. The original transition count is preserved; the separate class cap counts each generated nonterminal union class and one unit per terminal solve. Neither count measures total CPU effort. Complete expansion is rejected before mutation when either cap would be exceeded. No partial expansion or frontier eviction. Original default unchanged.
