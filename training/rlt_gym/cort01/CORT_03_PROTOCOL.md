# CORT-03: action-value controller with paid constraint evidence

Status: exploratory public development pilot. Run `node training/rlt_gym/cort01/run_actions.mjs`. The original CORT-01 episode generator is reused unchanged. No native model inference or BPD intervention.

## Environment
Four query slots (including a duplicate method), one fresh-context requery (existing second-wave candidate; a proxy for repair, not a conditional LLM rewrite), and two independent exact residue checks modulo 3 and 5. A query or check costs one synthetic unit; a fresh requery costs two. Each action may be used once. An audit tests the current candidate and returns only a boolean result, with the tested candidate and modulus; the environment uses the independent oracle's true answer to compute this partial signature. This is a deliberately available paid oracle-derived information channel, not an oracle-free model benchmark. Multiple candidates can survive a check. All accepted candidates must have been observed and satisfy every purchased residue fact. A policy cannot query the oracle directly, see the task truth, future branch outcomes, or latent error flags. If all observed candidates are excluded, the policy must acquire more evidence or return no answer at exhaustion.

## Action-value fit
Fit eight action-specific ridge regressions (30 public prefix features each) to the reward obtained by taking the proposed legal action and then following the frozen heuristic-stop continuation. Reward = final correctness minus 0.035 times remaining acquisition cost. Include STOP when an admissible answer exists or the budget is exhausted. Training states come from randomized acquisition and heuristic-full trajectories; evaluate every legal counterfactual action in the training simulator. This is fitted one-step policy improvement with a fixed continuation, not a Bellman-optimal planner or native recurrent controller. Replanning can deviate from the continuation used for labels. The learned policy greedily selects the estimated best action from public state. A learned-full control masks STOP while an acquisition is affordable. No threshold or lambda tuning on evaluation.

Three public seeds (2026112703..05), each 650 train / 320 ordinary evaluation / 320 shifted evaluation roots; exact task keys disjoint within each seed. Same worlds across policies and caps 4 and 6. Cross-seed duplicates are not ruled out. Compare query-only fixed order, fixed order with audits, adaptive heuristic-full and heuristic-stop, learned-full and learned. All use the same environment and candidate adjudicator. Report actual spend, branch calls, checks, requery counts, accuracy, utility and paired fixes/regressions. Equal hard caps are not equal realized cost; avoid claiming physical compute matching. Do not promote from these public synthetic roots. Future work: independently custodied roots, calibrated uncertainty and a recurrent/action-value head with evidence-aware representation, matched actual inference tokens/time and an external verifier whose costs are measured.

## Tests
Check root separation, audit access and consistency, immutable public state, finite learned parameters, legal actions, spend receipts, and answer provenance. No generated runs or checkpoints committed.
