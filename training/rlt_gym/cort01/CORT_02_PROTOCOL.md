# CORT-02: learned recurrent confidence and budget-matched controls

Exploratory public development only. Run `node training/rlt_gym/cort01/run_learned.mjs`. Seeds are public and may not be used as prospective evidence. Generated receipts are not committed. This extends CORT-01 and fixes its early-stop count: a decision at the hard budget is not an early exit.

## Frozen implementation

Three independent seeded development campaigns; each uses 900 train roots, 450 threshold-calibration roots, 450 ordinary evaluation roots, 450 shifted-error evaluation roots. Exact task keys are disjoint across each campaign's splits (subset tasks canonicalized by sorted multiset). Cross-campaign uniqueness is not guaranteed. All arms access only prefixes of role, method, answer and execution status; correct-answer targets are environment-owned and used during training/evaluation only. Twenty bounded features encode support, method overlap and contradictions, acquisition count and failures.

Compare the original tabular confidence, a 10-unit feed-forward confidence predictor (221 trainable parameters), a 10-unit weight-tied recurrent predictor (321 trainable parameters), and a recurrent predictor with its history connection cut at inference. Both fitted predictors train by binary cross-entropy on the correctness of the method-weighted leading candidate across seven prefixes, with 14 epochs of Adam, matching train roots, weight initialization for the feed-forward layers and learning rate. This is a small RNN, not a native TRM checkpoint or an implementation of BPD. The ablated history-cut arm is recalibrated. No model-generated code or external inference occurs.

The controller accepts only after two distinct executable methods support the leading candidate and confidence exceeds a threshold, or returns the leading candidate at the cap of seven. Select the threshold from a public 0.00..1.01 grid on calibration accuracy, constrained to at most four average branch acquisitions (tie break: lower cost). If infeasible, report it. Evaluation uses the frozen thresholds; realized costs may drift. At evaluation, construct an exact realized-call-matched nonadaptive grouped voting control with the floor/ceil of the adaptive average assigned using a seeded permutation independent of candidate outcomes; report paired fixes and regressions. This post-hoc resource comparator is descriptive, not a deployable prospective policy. Budget accounting covers simulated branch acquisitions, not GPU work or verifier time.

Report ordinary and shifted accuracy, calls, early stops, false early stops, decision Brier score and paired controls. The next gate requires prospective roots, a fixed-cost native baseline with server-side accounting, explicit repair/requery actions and externally verified labels. BPD causal claims require independent activation interventions; this experiment provides only a history ablation.
