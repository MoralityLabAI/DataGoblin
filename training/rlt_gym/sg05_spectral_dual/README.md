# SG-05: verified dual proposals and exact coordinate minimization

[SG-05 campaign and mathematics](https://github.com/MoralityLabAI/Compactification-Theory/tree/76993248cde75f49a77f39b5e31d70f3f3241802/research/spectral_geometry_v1/sg05). Extends the SG-04 trusted verifier; the student can propose bounded integer Lagrange multipliers in addition to search-state choices. `dual_bound` recomputes the independent-component relaxation. `coordinate_minimizer` sorts marginal relaxed-objective breakpoints, selecting the integer midpoint of a minimizing interval. Exact coordinate minimization of a nonsmooth convex function does not guarantee global dual optimality. The arithmetic is exact Python integers.

`DualSearchSession(task, initial_schedule, transition_cap=N, proposal_cap=M)` retains the independent transition cap and adds a separate proposal counter. `propose(t,s,eta)` accepts only a live state and a list of t integers of absolute value at most 100,000,000. The verifier recomputes the bound and keeps the minimum of the existing bound and the proposal, then applies ordinary certified pruning. Weak valid proposals still consume their slot; invalid proposals and cap violations are rejected without mutation. `advance(t,s)` is the original complete expansion. `receipt()` contains the ordered interleaved events. `verify_dual_trace` reconstructs the session and independently checks every event, incumbent, upper bound and gap. Student-supplied objective/gap fields are rejected. Same trusted-worker assumption as SG-04: students provide only events through an isolated or trusted interface and cannot directly mutate verifier internals. This is not an adversarial Python sandbox.

Four targeted Python tests passed locally in 0.24 s on the actual SG-03 and SG-04 source blobs (512 sampled small states with exhaustive remaining-schedule evaluation, coordinate alternatives, 40 arbitrary-priority interleaved proposal/expansion tasks, exact replay, cap atomicity, malformed input, empty prefix). An initial isolated test import failed because the old SG-04 fixture had a stub scoring module; replaced it with the exact SG-03 source and reran successfully. Full DataGoblin tests and Ruff remain pending.

The upstream 48-root synthetic development result supports analytic coordinate tightening. Learned warm starts yield smaller average root slack (2.729 vs 3.604 shuffled), but shuffled uses fewer action transitions (239.50 vs 244.04 at cap 2048). Do not promote learned warm starts over analytic/shuffled controls without matched wall time or counted dual arithmetic, fresh calibration and sealed evaluation. No native mechanistic or hardware performance claim. The student may generate coordinate proposals, but proposal caps do not bound external model time or wall time. Existing confirmation seals are unchanged.
