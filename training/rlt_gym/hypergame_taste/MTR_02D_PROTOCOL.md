# MTR-02D: certified anytime research search

Registered public development protocol. Successor to merged PR #97. Keep prior receipts immutable.

## Objective and worlds
Train a small branch-priority scorer to allocate a fixed number of exact search-state expansions. Use a finite research world with 64 Boolean assignments, positive integer weights, three nonlinear selector coordinates and three payload coordinates. A public branch-dependent observation DAG supplies gated probes and competing terminal certificates (full witness, branch certificate, coarse consequence, abstention). Different representation paths have different costs and wrong-path observations can be redundant. Train on two quadratic encoding families; ordinary uses new roots; OOD uses a cubic encoding and changes branch costs and distractor masks jointly. Use the same public root, candidate pool, prerequisite rules, integer arithmetic, and fixed research-credit budget for every arm. Enumerate the oracle by exact dynamic programming and verify terminal claims and explicit latent-world replay.

## Certified search
Initialize each discovered state with a feasible terminal/analytic rollout policy and an optimistic upper bound. The analytic library consists of prerequisite-closed single-path research plans (including prefixes and direct probes), evaluated by their finite observation partitions. It is a restricted library, not exhaustive subset search. Compare the library-only policy and one-/two-step contingent extensions on the same roots; disclose their actual gap. Refinement expands a previously unexpanded state, introduces all legal actions and their outcome states, and propagates max/sum lower and upper bounds through the reached DAG. Preserve the best feasible lower-bound policy at every node; the upper bound uses clairvoyant terminal reward with minimum probe cost and is never used as a publication certificate. At a fixed search budget choose the incumbent feasible policy, and evaluate it by explicit hidden-world replay. Charge exact state expansions as primary resource, and separately count all analytic-library evaluations, child transitions, bound backups and priority scoring calls. Shared preprocessing/oracle work is evaluator-only; count root policy initialization and baseline computation separately. No wall-clock or RSS claim from operation counts.

Compare deterministic optimistic-gap, mass-weighted gap, depth-first, random and a small supervised learned priority using public branch/state features. All use the same expansion/backup engine, feasible incumbent and candidate states. Train the priority head only on training roots using exact remaining value improvement as a label; exact values on evaluation roots are restricted to verification. No test-time tuning. If the learned policy does not beat the strongest deterministic scheduler at matched expansion budgets, retain the negative result. Report lower bound, upper bound, oracle gap and work by root, and realized policy utility equivalence. Use multiple training initialization seeds if the fitted model is stochastic; a deterministic regularized fit needs only one initialization. Public development namespaces, no sealed holdout claim. Measure at several expansion budgets, including 0. Report any deviations. 

## Memory and native integration
The reached DAG is a typed evidence object suitable for BPD/MMS; log reachable-state counts and reuse, but no claim of learned BPD activation retention or byte-bounded process memory in this experiment. Real CPU time/RSS, native GPTStoryworld/TRM/LDT, independent proof-level validation and larger private tests remain separate.
