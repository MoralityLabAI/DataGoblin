# MTR-02B: sufficient-state compression and measured evidence-cache pilot

Registered public-development protocol. Separate successor to MTR-02A. No private holdout or native neural mesh claim.

## Controlled mathematical worlds
A hidden h in F2^d with positive integer prior. A root supplies a public finite probe bank. One-use actions reveal exact binary sketches; setup actions unlock gated probes. A nuisance bit corrupts selected sketches. The terminal action may abstain or publish a complete witness; correct/incorrect rewards +20/-30 and research credits subtracted. Finite exact witness checks use box-LP optima, invertible binary systems, and triangular Boolean systems (OOD only). Underlying observations use a public encoding. Training d=4,5; ordinary d=4,5; OOD d=5 (triangular system and changed gates/costs). Horizon is 7 or 8 credits/visits. Enumerate latent worlds exactly. A state is compatible-world bitset, used-action bitset, remaining credits and visits. Exact Bellman value, with independently coded replay of probe legality and rewards, is the teacher. Root-conditioned expected utility is the primary outcome.

## Learned controller
Use a common fixed-size action feature vector and learned action-value head. Compare four equal-parameter recurrent/readout models: full sufficient-state token, restricted history RLT (4, 8 and 16 latent coordinates are separate capacity tiers), fixed-damping history, pooled history. At a given width match parameter counts, supervision, initialization and data ordering; full-state access uses a public fixed projection or exact bitset features, and is disclosed as a stronger observation arm. The full-state arm must have access to the complete compatible-state and used-action masks, even if the head has a bottleneck. Use three model initialization seeds; fit only on public training roots with at most four state presentations per root. Ordinary/OOD namespaces separate. Feature inputs may use public probe definitions and observed evidence but never exact future Q values, hidden truth, or evaluator-only state. Raw-history arms receive action/outcome tokens, common public instance features and remaining budget; no oracle posterior. Terminal macro is shared and uses publicly computed posterior (declare this external computation). Measure policy utility, false publication, query credits and seed sensitivity. Evaluate same-state/different-order histories on public roots, with exact continuation equality and action-value disagreement. Scope: finite deterministic-observation proxy, not theorem-level VC compression.

## Cache experiment (separate from policy learning)
Memoize exact integer continuation values keyed by the sufficient state in a fixed-size, explicitly byte-counted cache. Test 0, 4, 16 and 64 KiB payload capacity, with equal-byte shuffled/unrelated-key controls and conventional exact-key LRU; use a deterministic fixed-record typed-array representation, including key and metadata bytes. Use the same query sequence, no hidden-answer leakage across training/evaluation roots, and independently compute exact values for comparison. Report hits, misses, operations, allocated bytes and logical bytes; do not infer RSS or wall-clock savings from operation counts. Cache reuse must preserve all answers. A utility-aware admission rule, if evaluated, must use only past public work counters. This is a small exact-state memory scheduling proxy for MMS, not a BPD activation map or a full RAM-scaled native implementation.

## Decision
Public development diagnostic only: RLT must improve root-paired utility over fixed damping and pooling with <=5% more queries and <=0.005 higher false-publication probability, and compare to the complete-state controller. Report intervals; no promotion on pooled tie or OOD loss. Cache claims require bit-identical results and equal-byte controls; no claim of wall-clock acceleration without timing. Keep all negative results. No 1B training, private seed campaign, full Python CI or native GPTStoryworld claims.
