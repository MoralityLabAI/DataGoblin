# Local Jacobian audit for ALEPH-02

Register before the architecture holdout is opened. This fixed diagnostic extends the directional gain measurements without adding a promotion criterion. Analyze the frozen three-pass direct, damping, RLT, magnitude-clock and visit-clock fits. For each of the four held compositions, select its first root from a different one of the four task families in registered task-array order. Compare clean and strength-1.25 targeted trajectories. Keep the original prelude and matched perturbation fixed while differentiating a visit.

For each of the three visits form the full Jacobian of the unblended two-block core using centered differences on every input coordinate. Each example has 4W coordinates. Set the displacement on the varied coordinate to .01 times the RMS of the current state. Compute all singular values in float64 from the float32 forward evaluations. Report the largest singular value, Frobenius norm divided by sqrt(4W), and the norm of J-I. Check sensitivity of every fourth case to halving the step. These are finite-difference estimates at four concrete proof states and use the same held roots and weights across schedules. A separate per-token alpha can change the tangent of a gated transport. This diagnostic measures the proposed core map before that gate. The existing main assay already records the actual realized displacement after the gate.

The local diagnostic command is `bounded.py --wall 900 --core 0 arch_spectral.py --out OUT`. It opens the private seed only after the primary scorer has verified all checkpoints and created the bound draw. A released core can run the fixed basis sweep while the other primary score partitions finish. The resulting receipt publishes aggregate norms without inputs, answers or seed.
