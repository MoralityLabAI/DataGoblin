# ALEPH-03 paired receipt decoders

This registration freezes the design before drawing a new containment panel. The primary question is whether a fresh recurrent C reader of frozen v2 C uploads beats the same reader trained without a message. The other seventeen sender/reader pairs are secondary. The prediction is a probability and the loss is expected Brier over all eight equiprobable worlds and the native query distribution.

Use the primary LDT checkpoint of each C, D and MLP sender at seeds 137, 163 and 191. Check the v2 manifest, primary digest and its coordinated parent's digest. Only one thresholded bit crosses the interface. Each receiver gets the public rival masks, calibration-axis mask, status flags and verified side bit. Query weights, realized world, sender features, sender logits, cell mass and current frame identity are inaccessible to the receiver. No sender is updated.

Cross each sender with six receiver families and four separately fitted channel conditions. Side-only has a neutral absent-message input. Constant always transmits zero. Shuffled integrates every within-frame, within-query, within-side reassignment of the original binary uploads. It preserves the exact upload marginal conditional on the public query and side and destroys conditional target information. Valid uses the actual hard bit. Side/constant and valid/shuffle each have identical observable cell masses. The null upload can still communicate a frame-dependent marginal across frames. Quantify this directly with the learned shuffle control.

C and D reuse the two-visit width-32 v2 readout. MLP reuses its width-32 two-hidden-layer readout. Logistic uses a single affine layer on the identical public features and signed side/message. The empirical conditional estimator backs off from the exact public context to mask widths, calibration memberships and status, then status/side/message, then a global rate. It shrinks each level to its parent with eight pseudo-observations and a global half-success/half-failure prior. Each original training frame contributes 48 effective observations at native weights. The structured receiver enumerates hypothetical three-bit worlds consistent with the side bit; a rule survives both rivals when each public mask contains at least one high coordinate. It learns 16 upload-likelihood logits indexed by public native status and hypothetical world, solely from the same authorized observable-cell frequencies. The symbolic geometry and uniform world prior are explicit algorithmic inductive biases. This actor never receives the actual world or encoder truth table.

Use all 24 original v2 training frames, in the same balanced seeded order in all gradient fits. Initialize sender-matched receiver families identically at 100000 + training seed. Fit 500 one-frame Adam updates, learning rate .003, individual model gradient norm cap 1. Optimize expected squared error to positive cell frequencies with natural mass; this differs from unconditional Brier by a model-independent constant. Fit the empirical estimator once on the exact training frequencies. Save independent model checkpoints, source hashes, parameters and seeds before generating the held panel. No validation or hyperparameter selection.

Freeze all 216 fits before drawing four independent private generator panels (four relation/status families times four frames each, 64 frames total). Verify every full-frame digest differs from each old v2 and readout held frame and from the training frames. Record only digests and aggregate metrics in release artifacts. Compute exact frame-conditioned Bayes risks for both information sets and verify them against the independent native enumeration. Conditional mutual information in bits is H(Y | Q,S,frame) − H(Y | Q,S,M,frame). Calibration is frame-weighted ten-bin absolute expected calibration error; also retain mean signed prediction bias. All metrics give frames equal weight within each fixed relation/status family and give each family and private panel equal weight.

Report paired side-minus-valid loss as learned value, side-Bayes minus valid-Bayes as oracle value and their ratio when the aggregate oracle value exceeds .005. The numerator includes any difference in learned side calibration and can fall outside [0, 1]. Diagnose negative utility via the paired difference in excess risk and the constant/shuffle effects. Mark a useful pairing only if mean learned gain is at least .005; gain is positive on all three seeds, on every fixed family, and against constant and shuffled controls in aggregate; and the 2.5th percentile of 4000 paired bootstrap draws over training seeds and independent private panels is positive. Keep families fixed in this interval and report family sensitivity separately. Secondary gates are exploratory and this small assay alone cannot qualify a full-scale architecture. Cell metrics are exact conditional on the specified finite frames; three training seeds and four fresh panel draws limit generalization.
