# Can a small challenger certify a proof-ranker comparison more cheaply?

The acquisition replay improved candidate calibration while four-attempt proof yield stalled. This follow-up changes the observable to an actual decision. On one proof goal, a builder offers slate A of up to four tactics and a rival offers slate B. A small worker can ask the kernel about one candidate at a time, reuse past verified outcomes, and stop when every completion of the unqueried outcomes implies the same difference d = any_success(A) − any_success(B). Such a certificate becomes a synthetic supervision record with an explicit intervention, independent verifier and exact abstention condition. Unknown outcomes are unresolved. Count each unique check, including unsuccessful ones. Certificates allow decentralized contributions to combine on a common goal, prover version and candidate content hash.

**Exact characterization.** A difference of +1 requires evidence of a positive in A and negatives for every candidate in B. The negative case is symmetric. Equality is also forced when both slates have a known success, both have only checked negatives, or the two remaining Boolean functions of the unresolved outcomes are identical. For example if both sides still depend on the same two unchecked tactics, those tactics need no checking. To prove necessity, after absorbing known successes and deleting checked negatives, each side is a constant or a disjunction of distinct free variables. Two such functions coincide exactly if their constants or residual variable sets agree. With independent unconstrained bits the other forced differences require the two appropriate opposite constants. This certificate remains valid under arbitrary dependence among true grades; treating every completion as possible can cost extra checks.

**Competing policies.** Exhaustively run the union, or scan lexical order and stop when the certificate is conclusive. Compare both to random scanning, a cheap common-first/high-success rule and adaptive cost minimization under learned Bernoulli outcome priors. In the latter, the terminal cost is zero for a decisive record. For a free candidate i minimize 1 + p_i V(record + success_i) + (1−p_i) V(record + failure_i). Solving the small finite tree gives the optimal expected stopping cost under the assumed distribution. A misspecified prior can squander checks but cannot change a logically certified comparison. A complete-outcome census independently tests the stopping predicate.

**Public pilot specification.** Use the existing Lean replay and frozen split. Use A = the lexical first four and B = the four emitted by each of the three 96-check target-weighted students. Refit each from its recorded training acquisition IDs. Give all policies the same learned bucket probabilities. Blind the decision tree to held labels until a particular query is purchased. Compare the exact certified difference, unique checks and number of goals fully decided across 28 held goals and all three students. Random order uses the paired student seed. The exhaustive union comparator shares identical candidates. Keep the lower-cost, early-stopping baselines. Charge discovery costs separately from online calls and report how many slates were identical. Use the archived grades for retrospective external verification. This comparison is public development work; gains in audit efficiency are separate from any improvement in a fresh language model.

A falsifier for the cost model is a higher real query count than a simple stopping rule at the same certified outcomes. A separate falsifier for the broader data theory is that adding these certified comparisons to a fixed student's training mix fails to improve new-family selection at fixed total cost. This experiment tests the first claim.

## Results and the cheaper competing explanation

Across the same 84 goal/student comparisons, complete union replay cost 492 candidate checks. Random order with exact stopping cost 409, lexical order 448, and the learned-prior optimal tree 328. All returned the exhaustive decision. The lexical slate's net advantage over the acquired rival was 0, 4 and 4 goals by seed. None of the paired candidate sets was identical. These are replay debits for independent policies; 84 comparisons reuse 28 public goals.

Two post-hoc rivals tested whether learning deserved the credit. A tree planned with a flat 0.5 prior cost 440 checks. A rule that simply checks the symmetric difference first cost **104, 112 and 112**, exactly the learned planner's count on each seed. Once all exclusive tactics fail, both slates have the same residual success condition. This explains how a small participant can save verifications using only a list comparison and shared negative receipts. On this panel the stronger planner earned no additional call savings over that rule. Mark this rule as a prespecified control on the next generator. The savings concern the cost of *establishing the same decision*. Demonstrating training value requires a new student and independently held families.
